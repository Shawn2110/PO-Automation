# Design Context — PO Automation

## Users
Indian construction-company accountants and finance reviewers processing
vendor GST tax invoices for BuildCo Infra. Two roles: accountant (uploads,
edits, ships) and viewer (read-only oversight). They use the tool on desktop,
mostly during business hours, with intermittent attention — they need to
trust the numbers without re-reading every field. The viewers in particular
want a single glance at "what's outstanding and how long has it been there."

## Brand Personality
Calm · precise · trustworthy. Not a SaaS dashboard fighting for attention.
Not a tech-startup product trying to look clever. The tool fades into the
work; the work is what matters. A well-edited annual report, not a billboard.

## Aesthetic Direction
**Concept: Annual report meets shopfloor ledger.** Restrained typographic
hierarchy with confident moments of contrast. Warm neutrals tinted toward
amber (the brand accent) so the palette feels cohesive rather than stitched
together. Light by default — daylight desk work — with system-pref dark mode
for late-evening sessions. Information density on the dashboard / lists,
generous space on the login and detail pages.

Visual fingerprints that say *this product*:
- Hairline rules and gridded layouts; never a glass card with a drop shadow.
- Tabular monospaced figures for every number that adds up.
- A single warm amber accent — never a second accent colour competing.
- A serif display face (Vollkorn) used **sparingly** for one statement per
  page; the rest is a refined institutional sans (Public Sans).
- All-caps mono labels for category / status headings, never for body.

**Anti-references:** Linear-style frosted-glass dark dashboards. Stripe-style
gradient hero blocks. Any "AI for X" landing page from 2024-2025 with
purple/cyan gradients, rounded squircle icons over every heading, or
3-column "feature" grids. We are not those.

## Design Principles
1. **Numbers in monospace, prose in sans.** The eye should be able to scan a
   column of figures without re-finding the decimal each row. Tabular
   numerals on every digit (`font-variant-numeric: tabular-nums`).
2. **Amber is precious.** It appears on: the brand mark, the active nav
   indicator, focus rings, and primary buttons. Nothing else gets amber.
3. **Hairlines over shadows.** 1px borders in the neutral tone define every
   region. Drop shadows are reserved for elevation that actually requires it
   (overlays, dropdowns).
4. **The reader fills in the rhythm.** Vary spacing intentionally — tight
   triplets inside a card, generous breaks between sections. Never the same
   16px padding three layers deep.
5. **One statement per page.** Each screen has exactly one piece of content
   set in the serif display face: a dashboard headline, a login statement, an
   invoice number. Everything else is institutional sans.

## Type System
- **Public Sans** — body, UI, all interactive surfaces. Variable weights 300/400/500/600.
- **Vollkorn** — display, used sparingly. Italic 400 for editorial-style headlines.
- **JetBrains Mono** — numbers, codes, labels, category headings, status text.

(All three are free Google Fonts. None appear on Impeccable's reflex-reject
list. Replaced Instrument Sans + IBM Plex Mono which both did.)

## Theme
Light mode by default; dark mode via `prefers-color-scheme: dark`. Palette
expressed in OKLCH so lightness transitions are perceptually uniform. All
neutrals tinted ~3° toward the amber hue for subconscious cohesion.
